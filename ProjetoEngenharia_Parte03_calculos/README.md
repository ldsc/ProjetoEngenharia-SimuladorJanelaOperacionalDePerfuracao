# Projeto de Engenharia — Parte 3 (~75%)

Snapshot intermediário e compilável do Simulador de Janela Operacional de Perfuração.

## Implementado nesta etapa
- leitura dos dados do poço e parâmetros;
- Camada, Poco e ParametrosSimulacao;
- petrofísica (Wyllie e densidade bulk);
- geopressões (sobrecarga, tendência normal, Eaton e Gp);
- gradiente de fratura;
- estrutura de JanelaOperacional;
- cálculo e classificação da ECD;
- execução demonstrativa em linha de comando.

## Ainda em desenvolvimento
- consolidação pela classe Resultados;
- controlador SimuladorJanelaOperacional completo;
- exportações automáticas;
- interface Qt;
- geração e visualização dos gráficos.

Esta versão foi preparada para demonstrar a evolução incremental da implementação.
